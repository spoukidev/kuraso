# Kuraso brand assets

The "Highlighter" identity: lowercase **kuraso** in Bricolage Grotesque ExtraBold with a marker swipe across "ura". All text is outlined, so these SVGs render anywhere.

| File | Use |
|---|---|
| `kuraso-wordmark.svg` | Default logo on light backgrounds |
| `kuraso-wordmark-reverse.svg` | On ink `#151b33` or dark backgrounds |
| `kuraso-banner.jpg` | GitHub repository README banner & social preview (2:1, 1024×512) |
| `kuraso-lockup-tagline.svg` | Hero / lockup with the hand-written *read · mark · keep* |
| `kuraso-lockup-bilingual.svg` / `-reverse.svg` | Latin + Arabic (كراسو) |
| `kuraso-wordmark-mono.svg` | One-colour reproduction |
| `kuraso-app-icon.svg` | App icon master (source of `apps/desktop/src-tauri/icons/*`) |
| `kuraso-app-icon-night.svg` | Dark-tile alternative |
| `kuraso-favicon.svg` | 16–48px: favicon, small OS icon sizes, browser extension |

Colours: ink `#151b33`, paper `#fffdf5`, marker `#ffe14a`, mint `#7fe3b5`, sky `#8ccbff`, coral `#ff8a6b`, lilac `#c9b8ff`, ballpoint `#2f4bd8`, red pen `#c7381f`. Tokens live in `packages/ui/src/tokens.css`.
